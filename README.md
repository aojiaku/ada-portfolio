# Ada Johnson — Product Strategy & Operations Portfolio

This is an interactive portfolio I built to show real systems I've designed and run in Trust and Safety operations at Airbnb, along with career recognition and background.

**Live site:** [adaj-portfolio.vercel.app](https://adaj-portfolio.vercel.app/)

## What's inside

- **Problem Library.** A tool that turns scattered frontline feedback into a prioritized, searchable list. You can also ask it questions directly instead of digging through a spreadsheet.
- **Queue Health Monitor.** A dashboard that puts every team on the same three measures: how much work is coming in, how fast it gets handled, and how well it's done.
- **Capacity Model.** An interactive planner that connects team size and hours to actual workload needs, so priority conversations start with real numbers instead of a gut feeling.
- **Feedback Chat.** A small AI experiment. Instead of reading a static survey summary, you can ask the data questions directly.
- **Recognition.** Real feedback from managers, peers, and direct reports across Google, Airbnb, and earlier roles, organized by the themes that keep showing up.
- **Career Arc.** The throughline connecting three career chapters: staying close to the customer, learning to scale, and building the systems that help organizations learn.

## A note on the data

The first four sections are built on the structure and scale of real systems I've designed and run at Airbnb. To protect company information, the names, quotes, and numbers in those sections are made up. The Recognition and Career Arc sections use real feedback, with individual names replaced by role titles (Manager, Peer, Direct Report).

## Built with

Plain HTML, CSS, and JavaScript. No frameworks, no build step. Deployed on [Vercel](https://vercel.com/), connected to this repo so every push to `main` deploys automatically.
