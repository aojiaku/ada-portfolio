What if frontline feedback could talk back?

Most teams run employee surveys the same way: one check-in, a follow-up a few months later, then a slide full of numbers. I wanted something different, so I built a small experiment: instead of reading a summary slide, you can ask the data questions directly and get answers based on real themes and quotes.

Type a question below, or tap one to get started.
